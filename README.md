Stay Manager

Stay Manager is a Python-based application designed to simplify stay and accommodation management.

Features

* Stay and accommodation management
* Database integration using SQL
* Organized project structure
* Python-based application

Technologies Used

* Python
* SQL
* SQLite
* HTML/CSS (if used in the templates)

Project Structure

* app.py – Main application file
* schema.sql – Database schema
* requirements.txt – Python dependencies
* templates/ – HTML templates
* .gitignore – Excludes unnecessary files

How to Run

1. Clone or download this repository.
2. Install the required dependencies:
    pip install -r requirements.txt
3. Run the application:
    python app.py

Purpose

This project demonstrates practical skills in Python development, database management, and application structure.
